# German NLP-to-SQL Experiments

This project contains experiments with different **NLP-to-SQL approaches described in research papers**, with a specific focus on **German natural language queries**.

The goal was to test and compare different approaches for translating German questions into SQL queries, including different LLM-based and retrieval-based methods.

## Installation

Make sure you have **Python 3.10+** installed.

Navigate into the project directory:

```bash
cd sqlbuildqueryllm

python -m venv venv

source venv/bin/activate

pip install -r requirements.txt

python main.py

```
